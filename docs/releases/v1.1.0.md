## Andromeda Lite 1.1

A local AI desktop app: your models, on your machine, with memory, web search, files and tools. Nothing leaves your computer unless you ask it to.

### Highlights

**Design 1.1.** A new macOS-inspired interface with a floating translucent sidebar, system-blue accents, a glass message box and seamless title bars. It comes in light and dark mode, with its own incognito palette, and the window buttons stay usable above any dialog. The original look is still available as **1.0** (Settings → Appearance).

**Memory that works like Claude's.** Everything Andromeda remembers about you is organised into topics: You, Topics, Areas, People and Notes. Open a topic to read it, or describe a change in plain language and the local model rewrites it. You can also search past chats, keep sensitive topics out of memory, and import what another assistant knows about you.

**Meaning-based memory, on by default.** On first launch Andromeda downloads a small embedding model in the background (about 270 MB) and back-fills the memories it already had. "Which car did I like?" now finds "I like the Audi TT".

**Web search with links**, in five languages, with ad filtering and automatic fallback between search engines.

**Artifacts and projects.** Files the AI creates open in a side panel: HTML, Word, Excel, CSV, PDF and code. Projects keep their own folder of files as context.

**Faster and sturdier.** Preparing each message went from 28 ms to 2 ms, web searches are 2 to 4 seconds quicker, and the test suite grew to 1,257 tests running on Linux, macOS and Windows.

The full list is in the [CHANGELOG](https://github.com/PauAlonsoRacero/andromeda-lite/blob/main/CHANGELOG.md).

### Install

1. Install [Ollama](https://ollama.com) and pull a model. `qwen3:8b` is a good start; with 32 GB of memory or more, try `gemma3:27b`.
2. Download the file for your system below.

**macOS.** Unzip and drag Andromeda to Applications. The app is not signed with an Apple developer certificate yet, so the first time macOS will refuse to open it. Right-click the app, choose **Open**, then **Open** again. You only need to do this once.

**Windows.** Run the installer. SmartScreen may warn about an unknown publisher, because the installer is not code-signed yet. Click **More info**, then **Run anyway**.

### Upgrading from 1.0

Your chats, memory and settings are kept. If you used the macOS theme from a preview build, you'll start in Design 1.1 dark.

### Known limitations

- Answer quality depends on the model you run locally. Small models (under 8B) can get tool use and long instructions wrong.
- The apps are not code-signed yet, hence the warnings above.
